Import into your n8n

  1. 1In n8n: Workflows → ⋯ menu → Import from File — select the downloaded workflow.json.
  2. 2Connect your credentials: Supabase (Postgres) for the leads table, SMTP for the emails, and your Slack incoming-webhook URL for the hot-lead alert.
  3. 3The “Score Lead” Code node needs no changes — it already runs the scoring rules shown above.
  4. 4Activate the workflow and point your website form at the Lead Intake Webhook URL. New submissions now run the full pipeline automatically.
